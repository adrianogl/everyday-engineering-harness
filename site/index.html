## How it works

The main session reads your request in natural language and splits the work among small specialist agents. Before it writes anywhere outside your machine (commit, push, PR, Jira, Confluence), it stops and shows what it is about to do. You approve, change or cancel at each stop, and questions it cannot answer go back to you.

## Phases

One command per phase of a delivery. Each one says where it stops.

  1. /eeh:adr

    Writes the ADR from your template, contract first. Stops on open questions and before publishing.

    › /eeh:adr PROJ-7
  2. /eeh:adr-revisar

    Handles the open comments on a published ADR. Stops before updating the page.

    › /eeh:adr-revisar PROJ-7
  3. /eeh:quebrar

    Splits an approved ADR into one Jira card per repo. Stops on conflicts and before creating cards.

    › /eeh:quebrar PROJ-7
  4. /eeh:implementar

    Implements a card in its own worktree with plan, TDD and review. Stops at the plan, the commit and the PR.

    › /eeh:implementar PROJ-8
  5. /eeh:review

    Reviews a PR with reviewers per lens and keeps only blocking items two reviewers confirm. Stops before posting.

    › /eeh:review 42
  6. /eeh:qa

    Validates a delivery in QA with the screen and the contract endpoints, and saves the evidence. Stops before moving the card.

    › /eeh:qa PROJ-8
  7. /eeh:upstream

    Compares the parts with ECC, OMC and superpowers and merges what you accept. Stops before merging.

    › /eeh:upstream ecc

## Install

  1. Clone the repo:

    git clone https://github.com/adrianogl/everyday-engineering-harness ~/Code/everyday-engineering-harness

  2. Install it from the repo marketplace, inside Claude Code:

    /plugin marketplace add ~/Code/everyday-engineering-harness
/plugin install eeh@everyday-engineering-harness

    Or run it from the clone, for one session:

    claude --plugin-dir ~/Code/everyday-engineering-harness

  3. The profile lives outside the repo, in ~/.config/eeh/perfil.json. Start from the example:

    mkdir -p ~/.config/eeh
cp perfil.example.json ~/.config/eeh/perfil.json

    Without the file, the plugin warns that the profile is missing and keeps going.
