## Git

Nunca faça commit em main ou master: crie branch `<tipo>/descricao-curta` a partir da principal. Antes de `git commit`, `git push`, `git merge` ou `git rebase`, mostre as alterações e a mensagem proposta e espere confirmação explícita. Mensagem em Conventional Commits, em PT-BR, imperativo, minúsculas, sem ponto final. Sem trailer `Co-Authored-By` de assistente e sem menção a IA.
